# geschenk-franzi

Kleine statische Seite (HTML, CSS, Vanilla-JS). Kein Build-Schritt.

- Texte der Screens: `index.html`
- Dessert-Texte (Nachricht, Bestätigung, Übergabe): oben in `app.js` (`DESSERTS`, `WISH`)
- Link-Vorschau: `og:`-Tags in `index.html`, Bild `og.png`

Lokal ansehen: `python3 -m http.server` und http://localhost:8000 öffnen.
